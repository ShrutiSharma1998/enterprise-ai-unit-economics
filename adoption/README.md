**What is evidence and what is judgement.** Statements about the workbook come from inspecting the file. Statements about practice cite `evidence/` by ID. Anything marked (D) is our judgement. None of this has been tried in a real organization.

**Where this fits.** In FinOps terms the workbook is a Walk-level Planning & Estimating tool (a common template used at a gate, with a shared assumptions register). Connecting it to accounting, and carrying one estimate through several gates, is the Run level and is out of scope for v1.
